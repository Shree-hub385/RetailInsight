# RetailInsight – Power BI Dashboard

## Overview
This folder contains the Power BI dashboard and related documentation for the RetailInsight project.

## Dashboard Purpose
The dashboard is designed to help analyze retail sales performance and present useful business insights.

## Planned Analysis
- Total retail sales
- Total transactions
- Sales by product category
- Monthly sales trends
- Sales distribution by gender
- Average transaction value

## Data Source
Processed retail sales data from the Snowflake data warehouse.

## Visualization Tool
Microsoft Power BI
