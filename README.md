# RetailInsight

## Cloud-Based Retail Sales Data Warehouse and Analytics

### Project Overview
RetailInsight is a final-year academic project focused on retail sales data processing, cloud-based data storage, data warehousing, and business intelligence.

The project aims to transform raw retail sales data into structured information that can be used to analyze sales performance and generate business insights.

### Technologies
- AWS S3 – Cloud storage
- AWS Glue – ETL processing
- PySpark – Data transformation
- Snowflake – Cloud data warehouse
- SQL – Data querying and analysis
- Power BI – Data visualization

### Project Architecture
Retail Sales Dataset → AWS S3 → AWS Glue → Snowflake → Power BI

### Project Objectives
- Store retail sales data in cloud storage.
- Clean and transform raw data.
- Load structured data into a data warehouse.
- Perform sales analysis using SQL.
- Develop interactive dashboards using Power BI.

### Project Structure
- Data – Retail sales datasets
- Glue – ETL scripts
- Snowflake – SQL scripts
- PowerBi – Dashboard files and screenshots
